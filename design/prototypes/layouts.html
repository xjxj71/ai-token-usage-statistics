布局与动效原型 · 4 种范式

同一份模拟数据，不同的信息架构与动效语言。布局不再沿用现有长页面，按各范式重新组织。
配色主题原型见 上一轮 4 套主题；两轮可自由组合（如「布局 2 + 晨雾主题」）。
1 · Bento 控制台单屏 · 深色

12 列 bento 网格，一屏装下全部关键信息，无长滚动。费用 hero + 环形命中率 + 趋势 + 套餐 + 分布 + 实时动态。

动效：卡片交错入场 / 数字滚动 / 悬停浮起+顶部光线 / 折线绘制 / 环形扫入 / 动态流滑入高亮
2 · 侧边导航 SPA分区视图 · 浅色

左侧导航把长页面拆成独立视图（概览/趋势/记录/会话/定价/数据），每屏聚焦一件事。导航可点击，记录行可展开。

动效：导航指示器滑动 / 视图出场+入场过渡 / 行交错 / 展开行高度动画 / 切换时图表重绘
3 · 滚动叙事编辑风 · 浅色

保留单页滚动但做成「杂志章节」：hero 大数字 → 编号章节依次展开；滚过 hero 后关键 KPI 压缩成吸顶条随时可见。

动效：阅读进度条 / 吸顶条滑下 / 章节滚入显现 / 图表进入视口才绘制 / 进度条滚入动画
4 · 实时信息流监控台 · 深色

以「正在发生什么」为中心：左侧实时使用流（SSE 新记录滑入），右侧固定摘要轨（KPI/套餐/分布）。适合挂着当监控屏。

动效：新记录滑入+绿色高亮渐隐 / KPI 数字跳动闪光 / LIVE 脉冲 / 暂停-恢复 / 摘要轨入场
